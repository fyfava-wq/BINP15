# BINP15 -- Processing and Analysis of Biological Data

Course repository for **BINP15: Processing and Analysis of Biological
Data** at Lund University.

This repository contains course materials, practical exercises, R
scripts, notes, and other resources developed while studying the course.

## Repository structure

``` text
BINP15/
├── README.md
├── lectures/          # Lecture notes and supporting materials
├── practicals/        # Practical exercises and assignments
├── scripts/           # R scripts and reusable code
├── data/              # Datasets used in exercises (when permitted)
└── reports/           # Analyses, figures, and written reports
```

*The folder structure may change as the course progresses.*

## Tools and software

-   **R** -- statistical computing and data analysis
-   **RStudio** -- integrated development environment for R
-   **Git** -- version control
-   **GitHub** -- repository hosting and collaboration

Additional R packages will be documented in the relevant scripts or
practical notes.

## Getting started

1.  Clone the repository:

    ``` bash
    git clone <repository-url>
    ```

2.  Open the project directory in RStudio.

3.  Open the relevant `.R` script or practical exercise.

4.  Install any required R packages if they are not already available.

For example, install a package with:

``` r
install.packages("package_name")
```

## Working with data

-   Keep raw input data separate from processed data.
-   Avoid modifying original datasets; save cleaned or transformed
    versions separately when appropriate.
-   Document data sources and any preprocessing steps.
-   Do not commit sensitive, restricted, or very large datasets unless
    course instructions explicitly allow it.

## Naming conventions

Use clear, descriptive file names. Recommended conventions:

-   `lecture_01_notes.md`
-   `practical_01.R`
-   `assignment_01.R`
-   `figure_01.png`

Use lowercase letters and underscores rather than spaces in file names.
