1 Goal

Read a linear model as a biological statement: distinguish fitted values from residual variation, interpret model parameters in their units, and separate effect size from statistical support.

2 1. Read the model as a biological statement

Consider:

\[ y_i = \beta_0 + \beta_1 x_i + \varepsilon_i, \qquad \varepsilon_i \sim N(0,\sigma^2) \]

The line gives the model’s expected value of the response. The vertical deviations of observations from that line are the residuals.

2.1 1a. Identify parts of a regression plot

On a regression plot, label or sketch observed \(y\), predicted \(\hat{y}\), one residual \(\varepsilon\), and the fitted regression line.

Your answer / sketch:

2.2 1b. Interpret the parameters

What does \(\beta_0\) represent? What does \(\beta_1\) represent?

Your answer:

\(\beta_0\) is the intercept \(\beta_1\) is the slope

2.3 1c. Interpret the units

If \(x\) is leaf length (mm) and \(y\) is leaf width (mm), what units must \(\beta_1\) have?

Your answer:

The slope has units of mm/mm (millimetres of width per millimetre of length). This is a ratio of the same units, so it is dimensionless mathematically.

[ChatGPT comment] The important point is that the slope is not simply “no units”: it represents response units per predictor unit.

3 2. Intercept, slope, prediction and residual

Suppose:

\[ \hat{y} = 0.5 + 0.4x \]

Here, \(x\) is leaf length (mm) and \(\hat{y}\) is predicted leaf width (mm).

3.1 2a. Interpret the slope

Translate the slope 0.4 into a biological sentence.

Your answer:

For every 1 mm increase in leaf length, the model predicts an increase of 0.4 mm in leaf width.

[ChatGPT comment] The slope is 0.4 mm/mm. It does not mean that width is always 40% of length; it describes the predicted change in width for a 1-mm increase in length.

3.2 2b. Interpret the intercept

What does the intercept 0.5 mean mathematically? Would it necessarily be biologically interesting if no leaves approach 0 mm in length?

Your answer:

It is the predicted width when leaf length is 0 mm. If no leaves approach 0 mm in length, the intercept may not have much biological meaning.

[ChatGPT comment] The intercept is the model’s predicted response at x = 0, not just an arbitrary number added to the width. Your point about its limited biological meaning is correct.

3.3 2c. Make a prediction

What width does the model predict for a 10-mm leaf?

\[ \hat{y} =\text{4.5 mm} \]

3.4 2d. Calculate a residual

If that leaf actually has width 5.2 mm, calculate its residual using \(\varepsilon = y - \hat{y}\).

\[ \varepsilon = \text{0.7 mm} \]

3.5 2e. Interpret a negative residual

In words, what would a negative residual mean?

Your answer:

A negative residual means that the leaf’s observed width is smaller than the width predicted by the model.

4 3. What is actually assumed to be normal?

The model states:

\[ \varepsilon \sim N(0,\sigma^2) \]

A student says: “Linear regression assumes that x and y are normally distributed.”

4.1 3a. Identify the normal quantity

What does the model equation actually say is assumed to follow a normal distribution?

Your answer:

The model assumes that the random errors (ε) follow a normal distribution. Residuals are the observed-minus-predicted differences that we calculate and use to assess this assumption.

4.2 3b. Consider a skewed predictor

Could \(x\) itself be strongly skewed and the Gaussian linear model still be appropriate? Explain.

Your answer:

Yes. The predictor (x) does not itself need to be normally distributed. The model assumes that the errors around the expected response are approximately normally distributed (along with other model assumptions).

4.3 3c. Use residual plots

Why do residual plots help us assess whether the model is appropriate?

Your answer:

Residual plots help us see whether the model misses systematic patterns in the data—for example, curvature or changing residual spread. They help assess whether the model assumptions are reasonable.

10 R practical: fitting a linear model (from lecture notes)

Simulate data from a known linear relationship, fit the model, and inspect its predictions and residuals.

# Make the random numbers reproducible: rerunning this code gives the same data.
set.seed(85)
# Generate 200 predictor values (x), with mean 10 and standard deviation 2.
x <- rnorm(n = 200, mean = 10, sd = 2)
# Generate response values (y): 0.4 is the underlying slope, plus random noise.
y <- 0.4 * x + rnorm(200, 0, 1)

# Plot the observations; each point represents one paired x and y value.
plot(x, y, las = 1,
     xlab = "Leaf length (mm)",
     ylab = "Leaf width (mm)")

Fit the model and inspect its estimates and diagnostics.

# Fit a linear model: lm() estimates a straight-line relationship between y and x.
# In the formula y ~ x, y is the response and x is the predictor.
m <- lm(y ~ x)
# Display the model object's components, such as coefficients and residuals.
# str(m)
# Extract the estimated coefficients: first the intercept, then the slope for x.
cf <- coef(m)

Read the printed output from top to bottom:

  • cf: (Intercept) is \(\beta_0\); x is \(\beta_1\), the slope.
  • Estimate: coefficient value. Std. Error: its uncertainty. t value = estimate / standard error. Pr(>|t|): p-value for testing whether the coefficient is zero.
  • Residuals: observed minus predicted values; the five numbers summarize their spread.
  • Residual standard error: typical residual size, in y units.
  • Multiple R-squared: fraction of variation in y explained by the model. Adjusted R-squared adjusts for the number of predictors.
  • F-statistic and its p-value: test whether the model with x improves on a model with no predictor. With one predictor, this tests the same zero-slope relationship as the x row.

So the fitted line is y = -0.401 + 0.433 * x. The slope says predicted y increases by about 0.433 units per one-unit increase in x. The intercept is predicted y at x = 0, which may not be meaningful if zero is outside the observed range.

# Predict y for every x value used to fit the model.
predvals <- predict(m)
# Arrange the next two plots side by side.
par(mfrow = c(1, 2))
#par(mfrow=c(2,2))
# Start the first panel with a scatterplot of the observed values.
plot(x, y, las = 1,
     xlab = "Leaf length (mm)",
     ylab = "Leaf width (mm)")
# Add the fitted straight line from model m to the current scatterplot.
abline(m)
# Draw residuals as vertical segments from each observed y to its prediction.
segments(x, y, x, predvals)
# Plot a histogram to inspect the distribution of the model residuals.
hist(residuals(m), xlab = "Residuals", las = 1)

# Return to a single-panel plotting layout.
par(mfrow = c(1, 1))

Draw the fitted line only across the observed range of x. .To keep the regression line within the data range, it is better to make predictions for new values of x spanning the data range and add the regression line using the lines function.

# Make 200 evenly spaced x values between the smallest and largest observed x.
newx <- seq(min(x), max(x), length.out = 200)
# Use the fitted model to predict y at each new x value.
predy <- predict(m, newdata = data.frame(x = newx))

# Create the scatterplot first; lines() below adds to this existing plot.
plot(x, y, las = 1,
     xlab = "Leaf length (mm)",
     ylab = "Leaf width (mm)")
# Connect the predictions to show the fitted line across the observed x range.
lines(newx, predy)

12 Exercise: Fit a regression to real data

Choose a dataset with a continuous response and a continuous predictor. Fit a simple linear regression, interpret the slope, make a figure with the fitted line, and write a short Methods and Results section.

If you do not have a dataset, use the bird data below. It contains brain mass and body mass for male and female birds. Body parts often scale with body size according to a power relationship:

\[ y = a x^b \]

Taking logs makes this a straight-line relationship:

\[ \log(y) = \log(a) + b\log(x) \]

Here, the slope \(b\) describes how brain mass scales with body mass. For example, a slope of 0.55 means that a 10% increase in body mass is associated with approximately a 5.5% increase in brain mass.

The separate male and female models are useful for describing each slope; the interaction model provides a direct comparison. If Sex includes an unknown category, the output will also show its intercept and slope differences relative to the reference sex.

For the reference group, the slope is 0.57529, so a 10% increase in body mass is associated with approximately a 5.75% increase in brain mass (0.57529 × 10%). The exact power-law calculation is \(1.1^{0.57529} - 1\), or about 5.6%.

12.0.3 3. Write up your analysis

Methods: We expected brain mass to scale with body mass according to a power-law relationship, brain mass = a × body mass^b. We log-transformed both variables and fitted separate linear regression models for males and females. We also fitted a model with a body-mass by sex interaction to test whether the slopes differed. The slope, b, describes how brain mass scales with body mass.

Results: Brain mass scaled with body mass (Fig. 1). In males, brain mass increased by approximately 5.5% for every 10% increase in body mass (slope = 0.55, SE = 0.010), and body mass explained 83.5% of the variation in brain mass. The estimated slope was slightly steeper in females (slope = 0.57, SE = 0.012), but the interaction model did not provide clear evidence that the male and female slopes differed (male slope difference = -0.025, SE = 0.015, t = -1.62, p = 0.105). The output also included an unknown sex category; its slope difference from the reference category was not statistically clear (p = 0.130).

13 Optional exercise: How measurement error affects the slope

The usual linear model assumes that the predictor, x, is measured without error. If the measured predictor contains random error, the fitted slope is often pulled toward zero. Random measurement error in the response, y, usually makes the estimates less precise but does not systematically pull the slope toward zero.

First simulate one dataset and fit the model before adding measurement error:

set.seed(10)
n <- 200
beta0 <- 2                 # True intercept
beta1 <- 1.5               # True slope
x_true <- rnorm(n, 0, 1)   # True predictor values
y_true <- beta0 + beta1 * x_true + rnorm(n, 0, 0.5)

# With no measurement error in x, the estimated slope should be near beta1.
summary(lm(y_true ~ x_true))

Repeat this over several error sizes. The reliability ratio is the proportion of variance in the measured predictor that comes from the true predictor. Dividing the observed slope by this ratio gives a simple correction under the assumptions of this simulation:

\[ K = \frac{\mathrm{Var}(x_{true})}{\mathrm{Var}(x_{true}) + \mathrm{Var}(error)}, \qquad \beta_{corrected} = \frac{\beta_{observed}}{K} \]

set.seed(11)
error_sds <- seq(0, 0.5, by = 0.05)
n_repeats <- 500
slope_x <- corrected_x <- slope_y <- numeric(length(error_sds))

for (i in seq_along(error_sds)) {
  error_sd <- error_sds[i]

  # Repeat adding error to x and record the fitted slope each time.
  slopes_with_x_error <- replicate(n_repeats, {
    x_measured <- x_true + rnorm(n, 0, error_sd)
    coef(lm(y_true ~ x_measured))[2]
  })
  slope_x[i] <- mean(slopes_with_x_error)

  # Correct the average slope using the reliability ratio K.
  K <- var(x_true) / (var(x_true) + error_sd^2)
  corrected_x[i] <- slope_x[i] / K

  # Add the same size of random error to y instead and record the slopes.
  slopes_with_y_error <- replicate(n_repeats, {
    y_measured <- y_true + rnorm(n, 0, error_sd)
    coef(lm(y_measured ~ x_true))[2]
  })
  slope_y[i] <- mean(slopes_with_y_error)
}

# Compare the uncorrected and corrected estimates when x has measurement error.
par(mfrow = c(1, 2))
plot(error_sds, slope_x, type = "b", pch = 16,
     ylim = range(slope_x, corrected_x, beta1),
     xlab = "Measurement error SD in x", ylab = "Mean estimated slope")
segments(error_sds, slope_x, error_sds, corrected_x, col = "grey50")
points(error_sds, corrected_x, pch = 17, col = "tomato")
abline(h = beta1, lty = 2)
legend("bottomleft", c("Observed slope", "Corrected slope", "True slope"),
       pch = c(16, 17, NA), lty = c(1, 1, 2),
       col = c("black", "tomato", "black"), bty = "n")

# Compare slopes when the same sizes of measurement error are added to y.
plot(error_sds, slope_y, type = "b", pch = 16,
     ylim = range(slope_y, beta1),
     xlab = "Measurement error SD in y", ylab = "Mean estimated slope")
abline(h = beta1, lty = 2)
legend("bottomleft", c("Estimated slope", "True slope"),
       pch = c(16, NA), lty = c(1, 2), bty = "n")

Interpretation: As error in x increases, the uncorrected slope tends to be smaller than the true slope (attenuation). The correction should bring the estimates closer to the true slope in this simulation. Error in y increases the scatter in individual estimates, but their average should remain near the true slope. The correction is not automatic proof that real-world measurement error has been fixed: it relies on knowing or estimating the error variance and on the assumptions behind the reliability ratio.
